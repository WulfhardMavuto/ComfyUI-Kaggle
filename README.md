## Paperspace Gradient

📓 **[comfyui-paperspace.ipynb](comfyui-paperspace.ipynb)** - ComfyUI notebook optimized for Paperspace Gradient with A6000 GPU

To use on Paperspace:
1. Create a new notebook in Paperspace Gradient
2. Select A6000 (or similar NVIDIA GPU) as your machine
3. Upload or clone this repository
4. Open `comfyui-paperspace.ipynb` and run the cells
