## Paperspace Gradient

📓 **[comfyui-paperspace.ipynb](comfyui-paperspace.ipynb)** - ComfyUI notebook adapted for Paperspace Gradient

### Paperspace Setup:
1. Create a new notebook in Paperspace Gradient
2. Upload `comfyui-paperspace.ipynb` or clone this repository
3. Select a GPU machine (Free-P5000 or better recommended)
4. Run the installation cell to set up ComfyUI
5. Use Pinggy or Zrok for tunneling to access the WebUI

### Paperspace Features:
- Uses `/storage` for persistent model storage across sessions
- Models are automatically linked to `/storage/comfyui-models`
- Compatible with Paperspace's Free GPU tier
